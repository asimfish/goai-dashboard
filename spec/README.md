# 五个工作流场景的摆位规格（scenes_v5_spec）

生成时间 2026-09-14 · 生成者：高级模型（claude）· 输入：`final_round/exports/wf0*/isaac_manifest.json`

## 这是什么

五个独立场景的**摆位设计**，一个工作流一份。它定的是**哪条臂服务什么、每件东西在哪一排、在弧上的哪个角度**——
这是此前一直缺的那个设计决定。**footprint（实测包围盒）不在这里**，由资产流水线量出来后用于解细间距。

## 摆位规则

**环带**：仪器落在服务它的那条臂基座周围 0.44–0.76 m 的环带内。
UR5e 腕部包络 0.85 m，工具轴另有 0.27 m 偏置；FR3 在 A 站有 0.25 m 基座。整个环带都在包络内有余量。

**三排**（半径带，对应 `PLACEMENT_STANDARD.md`）：

| 排 | 放什么 | 半径 |
|---|---|---|
| back | 箱式炉、干燥箱、离心机、XRD、试剂柜、搅拌台 | 0.72 m |
| mid | 天平、定量站、pH 计、研磨、漏斗架 | 0.58 m |
| front | 作业小件、架、玻璃器皿、坩埚、瓶 | 0.46 m |

一排装不下（同排间距 < 130 mm）时自动拆成两个子环，这是真实台面在一排放不下时的做法。

**角度 = 流程顺序**：弧上的角度按该臂**全流程**的步骤序号单调排开，跨排也保持。
所以沿弧扫一遍就是走一遍流程。wf01 实例：定量站 −178° → 研磨 −158° → 转运架 −139° → 存放架 −119° →
三个前驱体瓶 −100°/−80°/−61° → 样品台 −41° → 坩埚钳 −22° → 坩埚 −2°。

**例外**：B 段四台箱式炉保持 v4 原位（退让 975 mm、间距 129 mm、朝向 180°）——
这是全场唯一本来就合格的一组，论文里 R2 也是沿导轨服务一排炉，不强行弯成弧。
导轨做成 prismatic 关节，`q ∈ [−2.59, +0.10] m`，四炉停靠点 `q = 0 / −0.83 / −1.66 / −2.49`。

## 还没做的（明确边界）

- **实测 footprint**：需要打开 USD 量包围盒，本机没有独立 pxr，归资产流水线。
- **z 向**：一律取台面 `worktop_z = 1.00270`，落位后要按各资产实测的 `support_z` / `origin_z` 修正。
- **yaw**：除四台炉（180°）外未设，按"同排操作面朝同一侧"的规则由落位时确定。
- **零干涉/扫掠/可达的运行时认证**：归 5090。这份是几何设计输入，不是认证。
